Connect your campus

This app is ready for a private database. A campus administrator must finish the setup before staff can sign in.

  1. Create a Supabase project.
  2. Run schema.sql in its SQL Editor.
  3. Add the project URL and publishable key to supabase-config.js.
  4. Create the director account and campus using the setup guide.

The public website has no real student records. Do not add real student information until setup is complete.
